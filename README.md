FreshMart Online Store

A modern, responsive online grocery store demonstration built using HTML, CSS and JavaScript.

Project Overview

FreshMart is a demonstration e-commerce website designed to showcase grocery products through a user-friendly online shopping experience.

Features

- Responsive navigation
- Product catalogue
- 12 demonstration products
- Product search
- Category filtering
- Shopping cart
- Quantity controls
- Estimated cart total
- Email order enquiry
- Responsive design
- Browser local storage

Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

Project Structure

- "index.html" – Website structure
- "style.css" – Website styling
- "script.js" – Interactive functionality
